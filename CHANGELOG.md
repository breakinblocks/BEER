# Changelog

## 1.6.2 - 2026-08-23

### Fixed

- Restored compatibility with Apothic Enchanting 1.6.1 after its `gatherStats` method signature changed.
- Prevented client-side block placement prediction when applying an enchanting-table range modifier.

### Changed

- Added a main-hand swing animation when a range increase or decrease is applied successfully.
- Updated the optional Apothic Enchanting compatibility target to version 1.6.1 or newer.
